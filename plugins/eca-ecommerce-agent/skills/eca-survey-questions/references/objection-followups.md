# Objection types and follow-up banks

Use this when building the "What almost stopped you from buying?" question and its branched follow-ups.

How to use it:
1. From the evidence log, pick the 4 to 6 objection types with the most evidence for this brand.
2. Word each main option specifically, using the brand's details and the customer's language. The examples below show the level of specificity, not the final copy.
3. For each chosen option, write the follow-up using the starter bank, then rewrite it with the brand's real specifics (their shipping threshold, returns window, variants, origin).
4. Every follow-up is multi-select, randomised, 3 to 6 options, with "Other (please specify)" pinned last.

Where to find evidence for each type is listed so you can check before including it.

---

## Price and value

- **Main option examples:** "The price", "Wasn't sure it was worth the price", "It cost more than I usually spend on [category]".
- **Evidence:** reviews saying "pricey but worth it" or "expensive", competitor price points, AOV vs category norms.
- **Follow-up:** "What made the price feel like a hurdle?"
  - I'm on a tight budget at the moment
  - I wasn't sure it was worth it until I tried it
  - I've seen cheaper options elsewhere
  - Shipping added too much to the total
  - I was waiting for a sale or discount code
  - I wasn't sure how long it would last

## Trust in the brand

- **Main option examples:** "I hadn't heard of you before", "I wasn't sure I could trust the brand", "Wasn't sure where it ships from".
- **Evidence:** a new or small brand, few reviews, no About page, overseas fulfilment, comments asking "is this legit?".
- **Follow-up:** "What made you unsure about trusting us?"
  - I'd never heard of the brand before
  - There weren't many reviews
  - I wasn't sure where you're based or where it ships from
  - The website didn't feel established
  - I was worried I'd never receive my order
  - I couldn't easily find contact or returns info

## Will it work for me (efficacy)

- **Main option examples:** "Not sure if it would work for me", "Not sure it would work on my [hair type / skin type]", "I've tried similar products that didn't work".
- **Evidence:** reviews starting "I was sceptical", results-based claims, problem-solving products.
- **Follow-up:** "What made you unsure it would work for you?"
  - I've tried similar products that didn't work
  - Not sure it suits my [skin / hair / body] type
  - The results looked too good to be true
  - I couldn't find reviews from people like me
  - Not sure how long it takes to see results

## Choosing the right option (size, shade, fit, variant)

- **Main option examples:** "Sizing wasn't clear", "Not sure which shade to choose", "Didn't know which product was right for me".
- **Evidence:** multiple variants, size charts, exchange requests, reviews mentioning "ordered the wrong size", FAQ entries about choosing.
- **Follow-up:** "What made it hard to choose?"
  - The size guide or shade guide wasn't clear
  - Too many options to choose from
  - Couldn't see it on someone like me
  - Wasn't sure about the fit or how it feels
  - Worried about having to exchange it

## Shipping (cost, speed, location)

- **Main option examples:** "Shipping cost", "Shipping cost to the US", "Delivery time", "Not sure it ships to my country".
- **Evidence:** shipping policy, free shipping threshold, international orders, reviews about delivery time.
- **Follow-up:** "What was the concern with shipping?"
  - The shipping cost was too high
  - I didn't want to spend more to reach free shipping
  - Delivery would take too long
  - Not sure about customs or extra fees
  - Not sure it ships to where I live

## Returns and risk

- **Main option examples:** "Worried I couldn't return it", "Not sure about the returns policy".
- **Evidence:** returns policy (or lack of one), hygiene products that can't be returned, reviews about returns.
- **Follow-up:** "What worried you about returns?"
  - Couldn't find the returns policy
  - Wasn't sure I could return it once opened
  - Returning it looked like a hassle
  - Return shipping would cost me

## Ease of use

- **Main option examples:** "Not sure how to use it", "Looked complicated to apply", "Worried I'd get it wrong".
- **Evidence:** how-to content, application steps, reviews about learning curve, FAQ about how to use.
- **Follow-up:** "What made it seem tricky?"
  - Not sure how to use it
  - Looked like it would take too long
  - Worried I'd mess it up
  - Couldn't find a how-to video or guide

## Ingredients, materials and safety

- **Main option examples:** "Not sure about the ingredients", "Worried about sensitive skin", "Not sure what it's made of".
- **Evidence:** ingredient lists, allergy or sensitivity questions, materials, "clean" positioning in the category.
- **Follow-up:** "What concerned you about the ingredients?"
  - I have sensitive skin or allergies
  - I didn't recognise some ingredients
  - Couldn't find the full ingredient list
  - Not sure it's safe for [pregnancy / kids / pets]

## Website and checkout experience

- **Main option examples:** "The website was confusing", "Too much information on the page", "Checkout didn't work smoothly".
- **Evidence:** UX audit findings, Clarity rage clicks or drop-offs, long PDPs, payment issues.
- **Follow-up:** "What made the website hard to use?"
  - Hard to find what I needed
  - Too much information on the page
  - The page was slow to load
  - My preferred payment option wasn't there
  - Something went wrong at checkout

## Timing and need

- **Main option examples:** "Didn't need it right now", "Wasn't sure it was the right time of year".
- **Evidence:** seasonal products, replenishment products, reviews mentioning seasons or events.
- **Follow-up:** "What made the timing feel off?"
  - I didn't need it yet
  - Wrong season for it
  - I still had a similar product to finish
  - I was waiting for payday

## Subscription or commitment

- **Main option examples:** "Didn't want to be locked into a subscription", "Not sure how the subscription works".
- **Evidence:** subscription offers on the PDP, subscribe-and-save, reviews about cancelling.
- **Follow-up:** "What put you off the subscription?"
  - I didn't want to commit
  - Worried it would be hard to cancel
  - Not sure how often I'd need it
  - Wanted to try it once first
