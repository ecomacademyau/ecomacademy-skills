# Learned replies

The skill's memory between runs. One block per query type. It is updated after each run
and read at the start of the next.

Do not edit the counts by hand, but **do** correct the Pattern lines. That is the fastest
way to fix a reply that keeps coming out slightly wrong.

## Status meanings

- **DRAFT** — normal. Drafted every time for review.
- **CANDIDATE** — meets every promotion test. Ask once, then move to AUTO or DECLINED.
- **AUTO** — the member signed off. Sent automatically, still logged, still falls back to
  a draft when the case is unusual.
- **DECLINED** — asked, and the answer was no. Do not ask again.
- **DEMOTED** — was automatic and got something wrong. Back to drafting. Needs ten more
  sightings before it can be proposed again, and twice demoted means it stays manual.
